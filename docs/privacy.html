Kebijakan Privasi: Harga Jual (Hitung HPP & Harga Jual)

Berlaku sejak: 3 Oktober 2026 · Diperbarui: 3 Oktober 2026 (versi 1.1.0, fitur Pro)

Aplikasi Harga Jual (ID paket com.neimasilk.hargajual) adalah kalkulator HPP dan harga jual untuk usaha kecil. Aplikasi ini dirancang agar tidak mengumpulkan data pribadi.

Data yang kami kumpulkan

Tidak ada. Aplikasi tidak memakai akun atau login, tidak memuat iklan atau analitik, dan tidak pernah mengirim data resep, harga, atau usaha Anda ke mana pun. Kami tidak memiliki server.

Sejak versi 1.1.0 aplikasi memuat Google Play Billing Library untuk pembelian Pro. Library ini membuat aplikasi memiliki izin internet. Izin tersebut hanya dipakai oleh komponen Google Play untuk memproses pembelian dan mencatat diagnostik layanan pembayaran sesuai Kebijakan Privasi Google. Fitur perhitungan tetap berjalan sepenuhnya offline.

Data yang tersimpan di perangkat Anda

Daftar bahan, resep, harga, biaya, dan pengaturan yang Anda masukkan disimpan hanya di penyimpanan internal aplikasi di perangkat Anda. Kami tidak dapat mengakses data tersebut.

  • Cadangan: jika Anda memakai fitur "Simpan cadangan", file JSON disimpan ke lokasi yang Anda pilih sendiri (misalnya Google Drive). File itu sepenuhnya di bawah kendali Anda.
  • Pencadangan otomatis Android: jika fitur cadangan Google aktif di perangkat Anda, Android dapat menyertakan data aplikasi ini dalam cadangan akun Google Anda, sesuai pengaturan perangkat.
  • Berbagi daftar harga: gambar daftar harga dibuat di perangkat dan hanya dibagikan ke aplikasi yang Anda pilih.

Pembelian dalam aplikasi

Fitur Pro (sekali bayar) dibeli melalui sistem pembayaran Google Play. Pembayaran diproses sepenuhnya oleh Google; kami tidak menerima data kartu, rekening, atau metode pembayaran Anda. Aplikasi hanya menanyakan ke Google Play apakah akun Anda sudah memiliki Pro, lalu menyimpan status "Pro aktif" di perangkat.

Anak-anak

Aplikasi ini ditujukan untuk pelaku usaha dewasa dan tidak ditujukan untuk anak-anak.

Menghapus data

Gunakan menu Lainnya → Hapus semua data, atau hapus instalasi aplikasi. Karena tidak ada data di server kami, tidak ada yang perlu diminta untuk dihapus.
